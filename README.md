# 心情便签墙

一个纯前端、匿名、本地存储的便签墙网站。  
打开页面即可看到一张贴满鼓励短句的“心情墙”，你可以随时添加、拖动、删除便签，所有数据只保存在当前浏览器的 `localStorage` 中，不需要服务器和数据库。

## 功能

- 🏷️ 首次访问自动生成预制便签
  - 桌面端：24～30 张
  - 移动端：12～15 张
- ✏️ 手动添加便签，单条不超过 30 字
- 🖐️ 拖拽移动便签，位置自动保存
- 🗑️ 点击右上角 `×` 或双击便签删除
- ↩️ 删除/清空均可撤销：删除单张、清空全部都会入撤销栈，可连续撤销多步（6 秒内有效）
- 🧹 一键清空所有便签，逐张撕下动画 + 自定义确认弹窗
- 🎲 随机补充按钮：一键新生成 5 张随机便签
- 🔍 顶部搜索框按内容过滤便签
- 📤📥 导出/导入 JSON 备份，方便换设备迁移
- 📐 智能防重叠：随机生成时自动避开已有便签
- 🌗 暗色模式：跟随系统 `prefers-color-scheme`
- 📱 移动端适配：便签可 1/4 露出屏幕外（减少墙内拥挤），桌面端便签不超出屏幕、刘海屏安全区适配、禁双击缩放与长按菜单
- 💾 所有数据保存在浏览器本地，刷新后仍然保留
- 🎨 柔和纸张配色 + 多种动效
  - 便签弹跳出现
  - 拖拽浮起
  - 删除撕下效果
  - 弹窗缩放动画
  - 空状态浮动提示
  - 支持 `prefers-reduced-motion`

## 使用方式

直接用浏览器打开 `index.html` 即可，无需安装依赖、无需启动服务器。

```bash
# 如果只是想本地预览，直接双击 index.html
# 或者使用任意静态服务器
npx serve .
```

## 数据存储

- 存储位置：浏览器 `localStorage`
- Key：`sticker_wall_notes_v2`
- 保存内容：便签文本、位置、颜色、旋转角度、创建时间
- 注意：不同浏览器、不同设备之间的数据不互通；清除浏览器缓存/站点数据会清空便签

## 自定义预制便签

如果你想修改首次打开时显示的预制文案，可以编辑 `index.html` 中的 `config.presetMessages` 数组：

```js
const config = {
  colors: ['#fff2a8', '#ffd6e0', '#c6f6d5', '#bfdbfe', '#e2d1f9', '#ffe0c2'],
  presetMessages: [
    '保持好心情',
    '多喝水哦',
    '今天辛苦啦',
    // ... 在这里添加或修改
  ],
  desktopCount: [24, 30],
  mobileCount: [12, 15]
};
```
